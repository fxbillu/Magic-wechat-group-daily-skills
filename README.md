# Magic 微信群日报

把关注群，读成一份日报。

选择多个微信群，由你 Windows 电脑上的 WorkBuddy 在选定时间每天整理成独立日报；按日期看多群，按群看历史，也能组合搜索。配置、密钥和归档文件保存在本机的包外目录。

**Windows · WorkBuddy · 1.3.0-rc.5 源码测试候选**

[复制安装提示词](#安装与更新) · [下载候选 ZIP](https://github.com/fxbillu/Magic-wechat-group-daily-skills/releases/tag/v1.3.0-rc.4) · [Windows 试用说明](skills/wechat-group-daily/references/windows-acceptance.md)

当前 GitHub 源码新增每日一次的接续日报；通过 Git 安装/更新获取 rc.5。上面的已发布 ZIP 仍为 rc.4。已有配置与历史日报保留。

## 为什么做这个项目

每天在微信里来回切换不同的项目群，消息很多，项目的进展、问题和待跟进事项却散落在各段对话里。即使经常看群，也很难对整体项目进度有一个清楚的把控。

所以做了这套日报，把关注群每天的讨论整理下来，方便回看，也作为项目进度同步的素材。**目前开源的只有微信群日报部分**，包含按群生成日报、阅读、历史回看和搜索；更完整的项目进度整合与同步不在本次开源范围内。日报反映的是群内讨论，项目的实际进度和完成情况仍需相关负责人确认。

## 使用边界与数据处理

1. **只处理有权处理的数据。** 在自己的设备上使用本人账号，仅选择自己有合法访问和处理权限的群聊。能看到群消息，不代表可以任意导出、分析或公开传播；使用前应确认相关授权、群内约定及所在组织的数据管理要求。
2. **不得用于侵犯他人权益。** 不得未经授权访问他人账号或数据，不得用于监控、跟踪、骚扰、批量采集出售聊天内容，或其他违反适用法律法规及平台协议的用途。
3. **本机保存不等于完全本地处理。** 配置、密钥和归档文件保存在本机，日报由 WorkBuddy 调用模型整理。根据所用模型和宿主配置，群聊内容或片段可能发送至云端模型服务；具体传输、留存和使用方式取决于相应服务的条款与设置。本项目不承诺全程离线或数据绝不出机。处理敏感内容前，请先确认相关授权及服务的数据处理方式。
4. **分享前检查隐私与保密信息。** 原始聊天、日报和截图都可能包含成员身份、联系方式、客户信息或项目机密。转发、上传或公开展示前，应取得必要授权并脱敏；反馈问题时不要提交密钥、个人配置或未经处理的聊天记录。

## 桌面快捷方式

Windows 初始化保存配置时，会创建带报纸图标的 **Magic 群日报** 桌面快捷方式。重复初始化或恢复会更新同一个入口，不生成副本。双击自动启动或复用本地阅读服务，优先以 Edge/Chrome 独立窗口打开。

如需重建，在 WorkBuddy 使用同一 Python 执行 `tools/desktop.py install`。快捷方式和图标保存在本机包外目录，不上传到 GitHub；未初始化也可打开阅读指引。

## 每天只出一次

时间由使用者设置，推荐 21:00；每个关注群每天最多一份。统计从该群上次成功处理截止点到本次计划截止点的消息，报头标明真实起止时刻。失败重试复用原窗口，消息不够成篇时如实记录；截止后的消息进入下一份。更新现有同一条任务，不再单独运行早报、晚间采集或包外 next_range.py。

## 第一次跑通，看这三件事

1. **确认用对数据。** 本人账号、关注群、时区和包外目录正确；首次建议先试 1—2 个群。
2. **打开一份实际日报。** 先生成当前接续窗口的 HTML，核对话题、引文和署名。无消息、素材不足与失败分别说明。
3. **核对每天的任务。** 首报可读后，再按 [配置与复建指引](skills/wechat-group-daily/references/scheduling.md) 创建或更新 WorkBuddy 本地任务。

任务运行时电脑需开机、不休眠，WorkBuddy 保持运行；微信数据应能按本机现有流程读取。手动试跑和真正到点执行是两项结果。

## 以后怎么更新

对 WorkBuddy 说 **“更新 Magic 微信群日报”**。Skill 按本机安装记录更新程序，保留个人配置、历史和已有任务。

开发侧已完成必要修复与前后端联调。前一轮的 68 项公共检查中，67 项通过、1 项可选 Pillow 检查跳过；真实 Python API 到页面的关键流程通过合成输入验证。

**Windows 真实微信取数、模型首报、PNG 和实际到点执行，仍由使用者在本机反馈。** WAL 仅记录诊断并沿用原路径，不一刀切阻断；窄窗口里的 HTML 报纸可能需要横向滚动，可单独打开阅读。
