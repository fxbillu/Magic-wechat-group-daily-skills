# 变更记录

## 1.3.0-rc.4 — 2026-10-27

- 修复初始化恢复成功后遗留 last_error，避免 setup.py --status 继续误报 DECRYPTION_INCOMPLETE；兼容已有历史进度文件，查询状态不改写个人文件。
- 提供新的 Windows 安装 ZIP，包含 rc.3 的核心库解密、跨盘目录、中断回收和暖纸桌面图标，保留已有配置与历史日报。

## 1.3.0-rc.3 — 2026-10-27

- 日报解密默认仅处理核心库，跳过 FTS 和其他非必要库；显式尝试可选库时，其失败不再否定核心库成功，核心库缺失或失败仍阻断流程。
- 旧快照记录中的 FTS 更新不再触发核心数据过期；实际消息分片更新仍保留新鲜度保护。
- 初始化支持微信源库与日报数据位于不同 Windows 盘符，保留禁止写入源库内部的保护。
- 同一解密目录增加操作系统锁；新的中断临时文件在带标记的工作目录中安全回收，保留旧版无归属临时文件、现有配置和历史日报。
- 数据库层仍按共享分片解密，按群按日期归档；未新增加密 WAL 合并或消息原文自动过期清理。

本轮通过公共 CLI/HTTP 与合成平台边界检查；Windows 实际文件锁和跨盘操作仍需在使用者本机确认。

## 1.3.0-rc.2 — 2026-10-27

- Windows 初始化自动创建或更新唯一的 Magic 群日报桌面入口，附本机生成的报纸图标。
- 双击启动或复用阅读服务，优先打开独立阅读窗口；可单独重建快捷方式。
- 仓库与展示名称加入 Magic 前缀，保留内部 Skill ID、配置和数据目录兼容。

Windows Shell 快捷方式和图标的实际效果仍由使用者在本机验证。

## 1.3.0-rc.1 — 2026-10-27

Windows / WorkBuddy 测试候选版，等待使用者在本机验证。

- 首次对话初始化：确认账号、包外数据目录、稳定群 ID、生效日、时区和每日时间；失败保留旧配置与数据。
- 修复同名群覆盖、分片署名、错误引文归属、过滤搜索、空消息状态及重采后日报链接丢失。
- 解密候选验证后原子替换，真实解密或查询失败不破坏旧结果；WAL 仅作待核实诊断，不一刀切阻断原路径。
- 保留本地阅读风格，支持按日、按群、组合筛选和旧稿回看；附 WorkBuddy 每日任务配置、更新及复建说明。
- 逐文件白名单出包，包含完整前端、依赖和第三方许可；个人配置、密钥、聊天和日报均不入包。

Windows 取数、真实模型稿件、PNG 和实际定时运行由使用者后续反馈。
