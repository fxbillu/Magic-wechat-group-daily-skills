# 新旧版本效果对比

2026-10-27。本目录是确认效果用的本地预览，不是新版本发布。

## 查看

先运行 `python3 -B build-preview.py`，再运行 `python3 -B start-preview.py`，打开返回的本机地址。rc.6 已整合此布局，生成器直接使用正式渲染器；`layout-preview.py` 仅保留为早期提案记录，不再调用。默认端口 8877，可通过 `--port` 修改。关闭服务时，两个隔离阅读器会一起退出。

预览页支持左右对比、只看新版、只看旧版，以及四个内容入口：

- 阅读页：新版前置实算统计、主要话题与下一步，完整活跃表折叠；旧版保留原日报入口。
- 总览前置：对照旧版的长开场和正文，查看新版开头的消息规模、活跃时段、主要话题、参与分布与待确认事项。
- 完整故事线：直接定位完整报道，随后是人物动态、原文金句与问答；话题不在末尾重复。并排时等比例缩小，可单独打开。
- 搜索前后文：同搜“交接异常”，新版默认展开第一条命中的前后文。

不启动服务时，可直接打开 [旧版日报](pages/before-report.html) 和 [新版日报](pages/after-report.html) 查看静态成稿。

## 示例与来源

- 同一组 36 条虚构群聊、4 位虚构参与者，日期 2026-10-26。文案是为展示功能人工整理的演示，不是用户聊天或客户事实，也不是对真实模型质量的验收。
- 原有版本从生成时的 Git HEAD 导出；确切提交记录在 [sample.json](sample.json)。新版复制当前工作区显式发布清单内文件，不读取个人配置、密钥或历史。
- 两份稿件均通过各自实际 `check_story.py`，再由各自 `render_daily.py` 生成。新版统计从合成归档实算，分析与原句绑定到合成消息来源。当前新版直接使用产品中的总览前置排版，不再后处理正文布局。
- 阅读器的 Python API 与合成索引沿用实际程序；新版前端使用已整合的总览组件；自动展开脚本只用于预览。
- 两份报道正文相同，人物显示名不同。新版布局把统计、主要话题和待确认事项放到开头，完整故事线保留在后面；技术来源 ID 收进“核对原文”，不占正文版面。待确认事项与状态标签是人工编写、绑定示例原文的提案文案，尚未加入产品 schema，也不是自动任务状态提取。
- 新版单独阅读在 390px 使用正常字号的单列布局，不将桌面整页缩成小字；旧版排版保持原样。
- `runtime/` 是可重建的预览副本与合成数据，已在本目录忽略；`pages/` 保存可独立查看的静态成稿。
