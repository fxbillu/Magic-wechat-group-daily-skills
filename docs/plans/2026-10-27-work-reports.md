# 工作群日报与后台打开行为

## 已确认需求

- 用户实测无人点击时后台出报会打开网页；后台流程只更新文件和通知链接，主动双击桌面入口仍可阅读。
- 每群设置详细版／项目工作版，每群每天仍一份。工作版突出整体总结、今日任务、责任人、时间节点和群内进展，未知项留待确认。
- 项目工作版允许短任务，不受详细版 200／800 字地板与故事段数要求影响；纯图片或未转写语音仍不能假装理解。
- 用户要求主要完成源码与编排；本次只做静态检查，真实执行、模型和 Windows 验收留在用户电脑上。

## 范围与验收

模板存入包外的群配置，在采集时冻结到归档和待出报条目；稿件必须绑定同一模板及来源版本。已有历史保持原状，新归档使用新设置。提供命令、项目稿结构校验、来源展开、HTML 渲染与阅读页区分。

后台打开来自 Skill／定时任务提示词中的显式打开步骤；渲染本身不主动打开阅读网页。修改随包提示词，提供 `desktop.py ensure` 静默入口，CLI `launch` 保持用户主动打开。旧任务须在 Windows WorkBuddy 中编辑同一任务提示词；本仓库不能自行更新另一台电脑的任务。

不新增 GUI 框架，不替换其他开发中的桌面原型，不实现图片解码／理解，不合并并行安装器改动。逐项 Windows 验收见 [随包说明](../../skills/wechat-group-daily/references/report-templates.md#windows-验收待实际执行)。
