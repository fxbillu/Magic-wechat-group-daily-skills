# 群语音转写开发约定

日期：2026-10-27。用户确认：单条失败继续出报且标明缺失，可补跑；保留模型权重和依赖，只清理运行资源与临时音频，不改微信原库。

## 行为与验收

- 日常采集按关注群和冻结时间窗口转写语音，绑定群、来源消息、发言人与时间。成功文字进入素材归档及有效字数，失败保留占位与脱敏原因，HTML 显示成功/缺失计数。
- 每批只加载一次本地 Whisper，不因缺模型自动联网下载。语音在独立子进程运行，结束或超时后等待进程退出再回收工作目录。保留模型缓存；SILK/PCM/WAV 与按需解密媒体副本使用任务目录，不改微信原库或既有核心解密库。
- 正常重跑复用成功转写，显式补跑只重试未成功项。文字修订改变素材 revision；保留旧日报为 stale，旧 revision 不可冒充新素材完成。不扩大冻结窗口或改变较新日报游标。
- 保持无语音文本流程、配置、历史及每天一群一份的兼容性。
- 初始按 AGENTS.md 公共 CLI、真实 HTTP 和真实产物边界做合成 TDD，只替换 Windows 解密及 SILK/Whisper 外部边界，不读真实个人数据、不安装模型。用户随后明确收敛：后续重点为脚本和流程编排，不继续扩展／重复 Mac 运行测试；真实语音、模型及资源验证交由 Windows。此前已完成的合成检查只作辅助证据。
