## 改动与兼容

- F10：所有消息筛选列明确使用 `m.` 别名，避免 JOIN 后 username/date 歧义；chat 按 v1 契约精确匹配稳定 ID，不用群名或 ID 片段扩大筛选范围。继续使用绑定参数。
- 每日列表只包含真实采集/报告记录，以及有明确生效证据、当日应采集的关注群。无生效证据的旧名单不再向所有过去日期补造 missing；按群历史仍只返回实际记录。
- 最小配置字段为可选 `chats[].effective_from`，合法 `YYYY-MM-DD`，包含该自然日。缺失或无效表示范围未知；不从 created_at、首次归档或执行机今天猜测旧生效日。daily=false 不补应采集项；从当前配置移除群也不删除实际历史。
- 日期/群条目和矩阵单元格新增 `expected`：true 表示当日实际有记录，或有明确生效证据应采集；false 表示当前证据不在范围内；null 表示缺少生效证据。矩阵保留日期列对齐，范围未知或不在范围的占位格不能被前端计作历史欠账。原 collection/report 状态枚举和旧 state 保持兼容。
- 显式进入已关注群的未观察交点仍可返回说明，不因每日列表不补行而破坏 T1 详情入口。expected=false/null 的显式说明不代表历史采集失败。
- F08 的报告保留、版本及 stale 实现沿用 T1，没有重做；取消关注后实际报告链接仍可打开。

最小字段及兼容规则已在本对话提出，未修改共享合同。主控需协调 expected 的前端空白/范围未知展示及契约说明；新增关注或重新启用时应由 T2 记录本人确认的生效日，而不是替旧配置追溯填值。单一 effective_from 表达当前这一轮关注，不能声称完整记录了多轮取消/重新关注的历史区间；旧的真实产物仍保留。
